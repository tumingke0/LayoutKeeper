## 어떤 문제를 해결하나요

회사와 집에서 각각 외장 모니터를 쓰면, 케이블을 뽑을 때마다 macOS가 모든 창을 노트북 화면으로 몰아넣습니다. 다시 연결하면 데스크탑마다 창을 하나씩 손으로 옮겨야 합니다.

LayoutKeeper는 메뉴 막대에 상주하면서 외장 모니터의 각 창 위치를 기억합니다. **어느 데스크탑(Mission Control의 Space)에 있었는지도 기억합니다.** 모니터를 연결하면 클릭 한 번으로, 또는 자동으로 모두 원래대로 돌려놓습니다.

> 스크린샷은 예시 데이터입니다. 앱은 영어와 중국어 간체를 지원하며 시스템 언어를 따릅니다.

## 기능

- **모니터별 레이아웃**: EDID(제조사, 모델, 일련번호)로 모니터를 구분해 집과 회사 모니터의 레이아웃을 따로 저장합니다. 직접 고를 필요가 없습니다.
- **공용 레이아웃도 가능**: 외장 모니터를 한 번에 한 대만 쓴다면 "모든 외장 모니터가 하나의 레이아웃 공유"를 선택하세요. 회사든 집이든 같은 데스크탑과 창 배치가 됩니다. 위치를 화면 비율로 저장하므로 해상도가 달라도 맞습니다.
- **원래 데스크탑으로 복원**(macOS 26 이상). 같은 데스크탑에 있던 창들은 원래 순서대로 같은 데스크탑에 돌아가며, 두 그룹을 한 데스크탑에 몰아넣지 않습니다. 그보다 오래된 macOS에서도 현재 데스크탑에서 위치와 크기는 복원됩니다.
- **데스크탑 자동 추가**(공용 모드, 기본 켜짐): 연결하면 Mission Control에서 부족한 데스크탑을 추가합니다. 데스크탑을 삭제하지는 않습니다. 확인이 맞지 않으면 멈추고 직접 처리하도록 안내합니다. SIP를 끌 필요가 없습니다.
- **밝기·음량 키**: 밝기 키로 마우스가 있는 화면(내장 또는 외장)의 밝기를 조절하고, 화면 위쪽에 반투명 표시가 나타납니다. "외장 모니터 밝기를 내장 화면과 연동"을 켜면 주변광에 따라 MacBook 내장 화면이 밝아지거나 어두워질 때 각 화면의 상대 밝기 차이를 유지하면서 같은 폭으로 외장 모니터 밝기를 자동 조절합니다. 음량 키는 마우스가 어느 화면에 있든 Mac의 시스템 음량(현재 사운드 출력)을 3%씩 조절합니다. 외장 모니터의 HDMI 또는 DisplayPort 오디오로 소리가 나오고 macOS가 그 음량을 조절할 수 없을 때는 음량 키와 음소거 키가 DDC로 그 모니터의 스피커를 조절합니다. 밝기 하드웨어 제어(DDC)는 **Apple Silicon Mac에서만** 됩니다. 모니터가 응답하지 않으면 소프트웨어로 어둡게 합니다. BetterDisplay, MonitorControl, Lunar가 실행 중이면 키를 양보합니다.
- **메뉴 막대에서 모니터 입력 전환**: 메뉴의 "입력 소스 전환"으로 모니터에 DDC 입력 전환 명령을 보냅니다. 기본 목록은 DisplayPort 1/2, HDMI 1/2, USB-C입니다. 설정 → 디스플레이에서 이름 변경, 숨기기, 모니터 설명서의 값 입력, LG 대체 명령 사용을 설정할 수 있습니다. 모니터마다 처음 전환할 때 확인을 받고, Mac에서 유일하게 켜진 화면을 전환할 때는 매번 확인합니다. 전환한 뒤에는 원래 컴퓨터의 명령을 받지 않는 모니터가 많아서, 되돌릴 때 모니터 버튼이 필요할 수 있습니다.
- **이름 있는 레이아웃**: 모니터 하나에 "코딩", "회의"처럼 여러 레이아웃을 저장하고 메뉴 막대에서 전환합니다.
- **기록**: 모니터마다 최근 5개 버전을 보관하므로 언제든 되돌릴 수 있습니다.
- **미리 보기와 실행 취소**: 복원 전에 각 창이 어떻게 움직일지 볼 수 있고, 모든 복원은 클릭 한 번으로 취소할 수 있습니다.
- **추측하지 않음**: 창을 옮길 때마다 실제로 도착했는지 확인하고, 실패하면 되돌립니다. 같은 이름의 창을 구분할 수 없으면 사용자에게 묻습니다.
- **디스플레이 배치**: 같은 외부 모니터를 MacBook 위에 두기도 하고 옆에 두기도 한다면, 시스템 설정에서 끌어다 놓을 필요 없이 메뉴 막대에서 위치(바로 위·오른쪽·아래·왼쪽)를 고르기만 하면 됩니다. 그 밖의 위치(왼쪽 정렬, 어긋나게…)는 사용자 지정 위치로 저장할 수 있습니다. Mac 본체의 포트(왼쪽·오른쪽 USB-C나 HDMI 등)마다 배치를 묶어 두면, 다음에 그 포트에 꽂을 때 자동으로 전환됩니다. 수동 전환 후 15초 안에 **Keep**을 누르지 않으면 원래대로 돌아갑니다. 주 디스플레이와 해상도는 그대로이고, 창 복원도 일어나지 않습니다.
- **잠자기 방지**: 메뉴 막대에서 4가지 모드를 고를 수 있으며 각 항목 아래에 잠자기 조건이 짧게 표시됩니다. "끄기", "화면만 끄기 허용(시스템 유지)"(덮개를 연 상태에서는 배터리를 쓰거나 화면이 꺼져도 깨어 있고, 덮개를 닫았을 때는 전원이나 외장 모니터가 연결되어 있으면 유지), "화면·시스템 항상 켜기", 그리고 "덮개를 닫고 전원을 빼도 유지"(전원과 모니터를 모두 빼고 덮개를 닫아도 계속 실행되며, 모드를 끄거나 앱을 종료하면 시스템 잠자기 설정을 자동으로 되돌립니다).
- **전역 단축키**: ⌃⌥⌘S 저장, ⌃⌥⌘R 복원, ⌃⌥⌘Z 실행 취소. 바꾸거나 끌 수 있습니다.
- **자동 업데이트**(Sparkle): 업데이트는 서명으로 검증되며, 업데이트 후에도 손쉬운 사용 권한이 유지됩니다.

## 설치

1. [Releases](https://github.com/tumingke0/LayoutKeeper/releases/latest)에서 `.dmg`를 내려받습니다. M 시리즈는 **AppleSilicon**, Intel Mac은 **Intel**을 고르세요.
2. LayoutKeeper를 "응용 프로그램"으로 끌어다 놓습니다.
3. **처음 열 때**는 앱을 오른쪽 클릭하고 "열기"를 선택합니다. "시스템 설정 → 개인정보 보호 및 보안"에서 "그래도 열기"를 눌러도 됩니다. 앱이 자체 서명되어 있고 Apple 공증을 받지 않았기 때문에 이 단계가 필요합니다.
4. 3단계 안내를 따릅니다. "손쉬운 사용"을 허용하고, 로그인 시 실행할지 정하고, 첫 레이아웃을 저장합니다.

**업데이트**: 메뉴 막대 → "检查更新…"(업데이트 확인)을 사용합니다. 기본으로 하루에 한 번 자동 확인합니다. 모든 버전이 같은 인증서로 서명되므로 업데이트 후 다시 허용할 필요가 없습니다.
0.6.0 이하를 쓰고 있다면 마지막으로 한 번 새 버전을 직접 설치하고 손쉬운 사용 권한을 다시 허용하세요. 스위치가 켜져 있는데 동작하지 않으면 "−"로 LayoutKeeper를 지운 뒤 다시 추가하세요.

## 사용법

1. 외장 모니터의 각 데스크탑에 창을 배치합니다.
2. 메뉴 막대 아이콘 → "保存当前布局"(현재 레이아웃 저장)을 누르거나 ⌃⌥⌘S를 누릅니다.
3. 다음에 그 모니터를 연결하면 오른쪽 위에 알림이 뜹니다. "恢复布局"(레이아웃 복원)을 클릭하거나 ⌃⌥⌘R을 누릅니다.
4. 마음에 들지 않으면 ⌃⌥⌘Z로 취소합니다.

모니터를 연결했을 때의 동작(설정 → 일반):
- **먼저 묻기**(기본): 오른쪽 위에 닫을 수 있는 알림이 뜨고, 클릭하기 전에는 아무것도 움직이지 않습니다.
- **자동 복원**: 화면과 창이 안정된 뒤 복원합니다.
- **끄기**: 직접 복원할 때만 동작합니다.

자세한 내용은 [docs/USABILITY.md](docs/USABILITY.md)(중국어)를 보세요.

## 요구 사항

- macOS 14 이상. 원래 데스크탑으로 되돌리려면 **macOS 26 이상**이 필요합니다(macOS 27.0에서 테스트).
- 손쉬운 사용 권한이 필요합니다. 화면 기록이나 입력 모니터링 권한은 필요 없습니다.
- 외장 모니터는 동시에 **한 대**만 지원합니다.
- "시스템 설정 → 데스크탑 및 Dock → 디스플레이마다 개별 Space 사용"이 켜져 있어야 합니다(기본값).

## 제한 사항

- 데스크탑 간 이동에는 macOS 비공개 API를 사용하므로 시스템 업데이트 후 동작하지 않을 수 있습니다. 앱이 실행할 때 자동으로 확인하고 필요하면 이 기능을 끕니다. 같은 데스크탑 안에서의 복원은 영향을 받지 않습니다.
- Finder 창은 다른 데스크탑으로 옮길 수 없습니다. 위치와 크기는 복원됩니다.
- 앱을 실행하거나 종료하지 않으며, 탭이나 창 겹침 순서는 복원하지 않습니다. 전체 화면, Split View, 최소화된 창은 건너뜁니다.
- 하드웨어 밝기 조절은 Apple Silicon에서만 됩니다. 일부 모니터, 어댑터, 독, HDMI 포트는 DDC를 지원하지 않습니다. 입력 전환과 모니터 스피커 음량도 DDC가 필요하며, 이런 명령에 응답하지 않는 모니터도 있습니다.

## 자주 묻는 질문

**데이터를 수집하나요?** 아니요. 네트워크는 업데이트 확인에만 쓰며 GitHub에만 연결합니다. 설정에서 끌 수 있습니다. 레이아웃은 Mac의 `~/Library/Application Support/LayoutKeeper/`에만 저장됩니다.

**왜 어떤 창은 "확인 필요"로 표시되나요?** 같은 앱에 제목이 같은 창이 여러 개 있어서, 추측해서 옮기지 않기 때문입니다. 미리 보기에서 골라 주세요.

**macOS 14/15에서는 왜 데스크탑 간 복원이 안 되나요?** 예전 시스템 인터페이스는 macOS 14.5부터 막혔고, 새 인터페이스는 macOS 26부터 있습니다.

**어떻게 삭제하나요?** 앱을 종료하고 `LayoutKeeper.app`과 `~/Library/Application Support/LayoutKeeper/`를 지운 뒤 `defaults delete local.layoutkeeper.app`을 실행합니다. 마지막으로 시스템 설정의 "로그인 항목"과 "손쉬운 사용"에서 제거하세요.

**예전 이름이 SpacePort였나요?** 네. 0.4.0에서 이름을 바꿨고, 처음 실행할 때 예전 데이터를 복사합니다.

## 소스에서 빌드

Xcode 16 이상(Swift 6)이 필요합니다.

```sh
git clone https://github.com/tumingke0/LayoutKeeper.git
cd LayoutKeeper
./scripts/test.sh     # 선택: 테스트 실행
./scripts/build.sh    # build-products/LayoutKeeper.app 생성
open build-products/LayoutKeeper.app
```

키체인에 "LayoutKeeper Self-Signed" 인증서가 있으면 그것으로 서명합니다. 없으면 ad-hoc 서명이 되며, 다시 빌드할 때마다 손쉬운 사용에서 지웠다가 다시 추가해야 합니다. 기술적인 내용은 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)를 보세요.

Issue와 Pull Request를 환영합니다. [CONTRIBUTING.md](CONTRIBUTING.md)를 보세요. 버그를 알릴 때는 macOS 버전(빌드 번호 포함)과 "설정 → 诊断 → 一键自检"(자가 진단) 보고서를 첨부해 주세요. 보고서에는 창 제목이 들어가지 않습니다.
