# LayoutKeeper 0.6.8

## 改动
- **提示改用 macOS 系统通知**：恢复结果、保存结果等提示现在是系统通知。点一下打开 LayoutKeeper（恢复结果会打开结果面板），向右划掉即可关闭；「撤销」「查看」等按钮在通知的「选项」里。第一次需要提示时会请求通知权限；如果关掉了通知，最近一条提示会显示在菜单栏菜单里。
- **去掉了拔屏后自动删除空桌面**：删掉一个桌面会让后面的桌面顺序整体前移，下次接上外接屏时窗口会被放到错误的桌面上。这个功能已从设置中移除，之前打开过的也不会再执行。
- **去掉了拔屏后的「N 个桌面被移到了内置屏」提示**：它建议手动删掉这些桌面，同样会打乱桌面顺序。

## 更新
0.6.1 及以上：菜单栏 → **检查更新…**，辅助功能权限保持有效。

## English
- **Notices are now macOS notifications**: restore results, save results and other notices appear as system notifications. Click one to open LayoutKeeper (restore results open the results panel), or swipe it away to dismiss it. Buttons such as **Undo** and **View** are under **Options**. LayoutKeeper asks for notification permission the first time it has something to tell you; if notifications are off, the latest notice is shown in the menu bar menu.
- **Automatic removal of empty desktops is gone**: deleting a desktop shifts the order of the ones after it, so the next time you plug in, windows could land on the wrong desktops. The option is removed from Settings and no longer runs, even if you had turned it on.
- **The "N desktops were moved to the built-in display" notice after unplugging is gone**: it suggested deleting those desktops, which shifts the desktop order in the same way.
- **Updating**: from 0.6.1 or later use **Check for Updates…**; Accessibility permission is kept. Self-signed, not notarized: right-click → Open on first launch.
