# LayoutKeeper 0.6.17

## 改动
- **清理键盘**：菜单栏新增「清理键盘」，点一下就锁住键盘，方便擦拭。锁定时所有按键、音量和亮度等媒体键以及快捷键都不起作用，每块屏幕上显示倒计时和已挡住的按键数。点「完成」、倒计时结束或按住 Esc 3 秒都能解锁。时长在「设置 → 通用 → 清理键盘」里选，可选 30 秒、1 分钟、2 分钟或 5 分钟，默认 1 分钟，最长 5 分钟。同一处可以打开「同时锁住触控板和鼠标点击」，打开后光标还能动，用 Esc 长按或等倒计时解锁。电源键和 Touch ID 锁不住，擦的时候请避开。解锁后 Caps Lock 恢复成锁定前的状态。使用现有的辅助功能权限，不需要新权限。
- 其他功能和 0.6.16 一样。

## 测试情况
本版在 macOS 27.0（Apple 芯片）上编译测试，并在真机上试过锁定、三种解锁方式和锁触控板选项。

## 更新
0.6.1 及以上：菜单栏 → **检查更新…**，辅助功能权限保持有效。

## English
- **Clean Keyboard**: a new **Clean Keyboard** item in the menu bar locks the keyboard so you can wipe it. While locked, all keys, media keys such as volume and brightness, and shortcuts do nothing, and every screen shows a countdown and how many keys were blocked. Click **Done**, wait for the timer, or hold Esc for 3 seconds to unlock. Choose the time in **Settings → General → Clean Keyboard**: 30 seconds, 1, 2 or 5 minutes (1 minute by default, 5 minutes at most). The same section has **Also block trackpad and mouse clicks**. With it on, the pointer still moves and you unlock by holding Esc or waiting for the timer. The power button and Touch ID can't be locked, so avoid them while wiping. Caps Lock is set back to how it was before the lock. It uses the existing Accessibility permission and needs no new one.
- Everything else is the same as 0.6.16.
- **Testing**: built and tested on macOS 27.0 (Apple silicon), including the lock, all three ways to unlock and the trackpad option on a real Mac.
- **Updating**: from 0.6.1 or later use **Check for Updates…**; Accessibility permission is kept. Self-signed, not notarized: right-click → Open on first launch.
