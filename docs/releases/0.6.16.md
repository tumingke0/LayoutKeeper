# LayoutKeeper 0.6.16

## 改动
- **匿名的每日计数**：应用每天向 GoatCounter 发一次请求，用来了解大概有多少人在用。请求里只有应用版本和构建号、芯片类型、macOS 版本、屏幕数量（1、2 或 3 块以上）和本机随机生成的编号。不含个人信息，也不含窗口标题、应用名称、布局、显示器名称和序列号。发送失败就跳过，不会重试，也不影响使用。详见 README 的「会收集数据吗？」。
- 其他功能和 0.6.15 一样。输入源切换和显示器喇叭音量仍是实验功能，默认关闭。

## 测试情况
本版在 macOS 27.0（Apple 芯片）上编译测试，确认每天只发一次计数。

## 更新
0.6.1 及以上：菜单栏 → **检查更新…**，辅助功能权限保持有效。

## English
- **Anonymous daily count**: once a day the app sends one request to GoatCounter so we can see roughly how many people use it. It carries only the app version and build, the CPU type, the macOS version, the number of screens (1, 2 or 3+) and a random ID made on your Mac. No personal information, window titles, app names, layouts, display names or serial numbers. If the request fails it is skipped, never retried, and the app works as usual. See "Does it collect data?" in the README.
- Everything else is the same as 0.6.15. Input switching and display speaker volume are still experimental and off by default.
- **Testing**: built and tested on macOS 27.0 (Apple silicon), including a check that the count is sent only once per day.
- **Updating**: from 0.6.1 or later use **Check for Updates…**; Accessibility permission is kept. Self-signed, not notarized: right-click → Open on first launch.
