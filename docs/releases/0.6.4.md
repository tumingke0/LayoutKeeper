# LayoutKeeper 0.6.4

## 新功能
- **显示器亮度和音量**：菜单栏可直接调每块屏的亮度；外接屏通过 DDC 调亮度和音量（不支持时改用软件调暗），内建屏调系统亮度。亮度键（和音量键）调节鼠标所在的屏幕，屏幕顶部显示毛玻璃提示；每按一次 3%，⌥⇧ 微调 1%。BetterDisplay / MonitorControl / Lunar 运行时不接管按键，退出后自动接管。设置 → 显示器。
- **桌面管理**（原 0.6.3 实验功能，现为正式功能，共用模式下默认开启）：接上外接屏自动补齐桌面，拔掉后自动删掉挪到内置屏上的空桌面。

## 改动
- 去掉了「暂停自动恢复」（设置和菜单）。之前设置的暂停会自动清除。

## 说明
- 亮度：已在 DELL S2421HSX（DDC 读写）和 MacBook 内建屏上实测。Intel Mac 暂不支持 DDC，外接屏会改用软件调暗；Intel 版未在真机测试。部分显示器、转接头或扩展坞不支持 DDC。
- 桌面管理：已在 macOS 27 上验证调度中心加删桌面，真实拔插流程用户实测中。

## 更新
0.6.1 及以上：菜单栏 → **检查更新…**，辅助功能权限保持有效。

## English
- **Display brightness & volume**: per-display sliders in the menu (DDC for external monitors with software-dimming fallback; built-in via the system). Brightness/volume keys act on the display under the pointer with a glass HUD at the top; 3% per press, 1% with ⌥⇧. Yields to BetterDisplay / MonitorControl / Lunar while they run and takes over automatically when they quit.
- **Space management** (was experimental in 0.6.3; now a regular feature, on by default in shared mode).
- Removed "Pause auto-restore"; any active pause is cleared.
- Notes: DDC verified on a DELL S2421HSX; Intel Macs have no DDC yet (software dimming) and the Intel build is untested on real hardware.
- **Updating**: from 0.6.1 or later use **Check for Updates… (检查更新…)**; Accessibility permission is kept. Self-signed, not notarized: right-click → Open on first launch.
