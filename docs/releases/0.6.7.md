# LayoutKeeper 0.6.7

## 改动
- **自动恢复重写**：接上外接屏后的自动恢复，现在和手动点「恢复布局」走同一套代码，区别只是认不准的窗口不动。以前在家和公司之间换着接不同的显示器时，自动恢复经常什么都没做，手动却是好的，这个问题修掉了。
- **每接一次屏幕只恢复一次**：中途又来了显示器事件、或者别的任务正忙，会等一下再接着做，不会悄悄放弃。显示器只是闪断一下、零点几秒就回来的，不算重新接入。
- **桌面不够时先补桌面**：自动补齐桌面后，再把剩下的窗口放回原来的桌面，一次接入里做完。
- 自动恢复后还有窗口没动，会弹提示告诉你，点「恢复布局」可以手动处理。
- **Chrome 窗口按用户（Profile）识别**：Chrome 窗口的标题随网页一直在变，现在按它属于哪个 Chrome 用户来认。两个用户名字相同时也能分开。这一步要读 Chrome 的资料文件夹，有些 Mac 上需要给 LayoutKeeper 完全磁盘访问权限；读不到时会安静地跳过，不会弹窗。
- **亮度键每按一次调 5%**（以前是 3%），⌥⇧ 微调仍是 1%。音量键保持每次 3%。
- 拔掉外接屏后自动删除空桌面，改为默认关闭（设置里可以打开）。删桌面要经过调度中心，屏幕会闪一下。
- 所有提示的关闭按钮移到左上角。

## English
- **Auto-restore rewritten**: restoring after you plug in a monitor now uses the same code as clicking **Restore Layout**; the only difference is that windows it can't identify for sure stay put. Switching between different monitors (say, home and office) used to leave auto-restore doing nothing while the manual button worked. That's fixed.
- **One restore per plug-in**: if another display event arrives or the app is busy, it waits and carries on instead of silently giving up. A monitor that drops out for a fraction of a second and comes back doesn't count as a new plug-in.
- **Adds desktops first when needed**: if there aren't enough desktops, it adds them and then puts the remaining windows back on their own desktops, all in the same pass.
- If anything was left unmoved, a notice tells you, and **Restore Layout** handles the rest.
- **Chrome windows matched by profile**: Chrome titles change with every page, so windows are now matched by the Chrome profile they belong to. Two profiles with the same name can be told apart too. This reads Chrome's profile folder, which on some Macs needs Full Disk Access; if it can't be read, the step is skipped quietly, with no prompt.
- **Brightness keys step 5%** per press (was 3%); ⌥⇧ still gives 1%. Volume keys stay at 3%.
- Removing empty desktops after unplugging is now off by default (you can turn it on in Settings). It goes through Mission Control, so the screen flashes.
- The close button on every notice is now at the top left.
- **Updating**: from 0.6.1 or later use **Check for Updates…**; Accessibility permission is kept. Self-signed, not notarized: right-click → Open on first launch.
