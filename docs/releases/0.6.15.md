# LayoutKeeper 0.6.15

## 改动
- **在菜单栏切换显示器输入源**：菜单里新增「切换输入源」，选一项就给显示器发一次 DDC 输入切换指令。默认列出 DisplayPort 1、DisplayPort 2、HDMI 1、HDMI 2 和 USB-C。接两块以上外接屏时先选显示器再选输入。在「设置 → 显示器 → 外接显示器」点某块屏的「输入源…」，可以改名、隐藏、填显示器说明书上的数值（十进制或 0x 开头的十六进制），LG 显示器可以勾选「LG 备用指令」。每块显示器第一次切换会先确认，可勾选「不再提醒」；切的是 Mac 唯一亮着的屏幕时每次都确认。很多显示器报告的当前输入不准，所以菜单里不标当前输入。很多显示器切走后不再接受这台 Mac 的指令，切回要用显示器上的按键。不想要这个菜单可以在「设置 → 显示器 → 菜单栏」关掉。
- **音量键调显示器喇叭**：声音从外接显示器的 HDMI 或 DP 音频输出、macOS 又调不了这个音量时，音量键按 3% 一档调这台显示器自带的喇叭（⌥⇧ 为 1%），静音键也能用。提示框显示在这块显示器上，写明「显示器喇叭」。显示器不支持 DDC 静音时，按静音键会把音量调到 0 并记住原来的音量，再按一次恢复。读不到显示器当前音量时从 10% 开始调。声音走内建扬声器、耳机、蓝牙或 USB 声卡时和以前一样调系统音量，和鼠标在哪块屏上无关。开关在「设置 → 显示器 → 键盘」，默认打开。两块同型号显示器自动对不上时，可以在「外接显示器」里给每块屏手动选声音设备。
- **接两块以上外接屏时 DDC 对应更准**：LayoutKeeper 会先按每块屏自己的显示通道找到它的 DDC 通道，找不到时沿用原来的配对方式。亮度键和亮度滑块因此更不容易调到另一块屏上。对应关系确认不了的屏幕不能切换输入源，也不会调它的喇叭。
- 输入源切换和显示器喇叭音量只支持 Apple 芯片的 Mac。部分显示器、转接头和扩展坞不响应这些指令。

## English
- **Switch a monitor's input from the menu bar**: the new **Input Source** menu sends the monitor one DDC input command. The default list is DisplayPort 1, DisplayPort 2, HDMI 1, HDMI 2 and USB-C. With two or more external monitors you pick the monitor first. In **Settings → Displays → External Displays**, **Input Sources…** lets you rename or hide inputs, enter the value from the monitor's manual (decimal or hex starting with 0x), and turn on the **LG alternate command** for LG monitors. The first switch on each monitor asks for confirmation, with **Don't ask again**. Switching the Mac's only active screen always asks. Many monitors report the current input incorrectly, so the menu doesn't mark it. Many monitors also stop taking commands from the Mac once it is no longer the active input, so switch back with the monitor's own buttons. You can hide the menu in **Settings → Displays → Menu Bar**.
- **Volume keys control a monitor's speakers**: when sound plays through an external monitor's HDMI or DisplayPort audio and macOS can't change that volume, the volume keys change the monitor's speakers in 3% steps (1% with ⌥⇧), and the mute key works too. The indicator appears on that monitor and says **Display speakers**. On monitors without DDC mute, the mute key sets the volume to 0 and remembers the previous level, and pressing it again restores it. If the monitor's volume can't be read, adjusting starts from 10%. Built-in speakers, headphones, Bluetooth and USB audio work as before, wherever the mouse is. The toggle is in **Settings → Displays → Keyboard** and is on by default. If two monitors of the same model can't be matched automatically, choose each monitor's sound device under External Displays.
- **More reliable DDC with two or more external monitors**: LayoutKeeper first looks up each monitor's DDC channel through its own display connection and falls back to the previous pairing when that isn't possible, so brightness keys and sliders are less likely to reach the wrong monitor. A monitor whose channel can't be confirmed can't switch inputs or have its speakers adjusted.
- Input switching and display speaker volume need a Mac with Apple silicon. Some monitors, adapters and docks don't respond to these commands.
- **Updating**: from 0.6.1 or later use **Check for Updates…**; Accessibility permission is kept. Self-signed, not notarized: right-click → Open on first launch.
