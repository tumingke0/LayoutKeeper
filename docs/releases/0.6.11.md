# LayoutKeeper 0.6.11

## 改动
- **桌面按原来的顺序还原，空桌面也保留**：比如外接屏的第 1、2 个桌面空着，窗口都在第 3–5 个桌面上，那么换一块显示器或重新插上之后，窗口还是回到第 3–5 个桌面，前两个桌面继续空着；桌面不够就先补齐再放。以前会把窗口往前挪，空桌面被占掉，有时还会多补一个桌面。
- **macOS 打乱桌面顺序也能放对**：重新插上同一块显示器时，macOS 偶尔会把桌面换个顺序（甚至整个倒过来）还回来。现在窗口按你原来的顺序放回，并提示一句。拔屏后你在笔记本上删掉的空桌面，不会再被补回来。
- **合盖、锁屏、刚唤醒时不再记错**：合上 MacBook 只用外接屏时，macOS 会把笔记本的桌面都挪到外接屏上；锁屏或息屏时读不到窗口；刚唤醒的一两分钟里，macOS 可能还在报告一块已经拔掉的显示器。这些时候 LayoutKeeper 不再更新记录，拔屏时留下的是最后一次正常的样子。所以「在家合盖 → 拔屏 → 到公司开盖插上」之后，窗口会回到家里那样的桌面位置，笔记本屏幕上的窗口也不会被拉到外接屏上。
- **屏幕读不到时先等一等**：插上显示器时如果一个窗口都读不到（比如还在锁屏），先不恢复，过几秒再试。
- **旧布局不再干扰新布局**：较早保存的布局里的窗口，只有它原来的桌面还对得上时才会一起恢复，不会再打乱现在的窗口顺序。
- 提示更具体：缺桌面时会说清是第几个桌面的窗口还没放；有窗口没读全时会说是哪个应用的，和这次布局无关的应用不再提示。

## English
- **Desktops come back in their original order, empty ones included**: say desktops 1 and 2 on your external monitor are empty and your windows are on desktops 3–5. After switching monitors or plugging back in, the windows go back to desktops 3–5 and the first two stay empty. Missing desktops are added first. Before, windows were moved forward onto the empty desktops, and sometimes an extra desktop was added.
- **Right order even when macOS shuffles desktops**: when you plug the same monitor back in, macOS sometimes hands the desktops back in a different order, or even reversed. Windows now go back in your original order, with a short note. An empty desktop you deleted on the laptop after unplugging is not added back.
- **Nothing is recorded wrong with the lid closed, the screen locked or right after waking**: with the MacBook lid closed, macOS moves the laptop's desktops onto the external monitor; while the screen is locked or asleep no windows can be read; and for a minute or two after waking, macOS may still report a monitor that is already unplugged. LayoutKeeper no longer updates its record at these times, so what's kept at the unplug is the last normal state. Closing the lid at home, unplugging and plugging in at the office with the lid open now puts the windows back on the same desktops as at home, and windows on the laptop screen stay there.
- **Waits when the screen can't be read**: if no window at all can be read when a monitor is plugged in (for example the screen is still locked), LayoutKeeper waits and tries again a few seconds later instead of restoring.
- **Older layouts no longer get in the way**: windows from an older saved layout are only restored along with the current ones when their own desktop still matches, so they can't reshuffle the current order.
- Clearer messages: when desktops are missing you're told which desktops' windows are waiting; when some windows couldn't be read you're told which app, and apps that aren't in the layout are no longer mentioned.
- **Updating**: from 0.6.1 or later use **Check for Updates…**; Accessibility permission is kept. Self-signed, not notarized: right-click → Open on first launch.
