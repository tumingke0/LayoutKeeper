# LayoutKeeper 0.6.14

## 改动
- **外接屏亮度跟随内建屏幕自动变化**：在「设置 → 显示器 → 外接显示器」以及菜单栏亮度滑块下方新增「外接屏亮度跟随内建屏幕自动变化」开关。开启后，当 MacBook 内建屏幕随环境光或手动调节变亮、变暗（变化达 2% 及以上）时，外接显示器会按相同幅度自动增减亮度，同时保留每块屏幕各自的相对亮度差。合盖、锁屏或休眠时自动暂停跟随，开盖或解锁后重新建立基准，不会产生突兀跳变。

## 更新
0.6.1 及以上：菜单栏 → **检查更新…**，辅助功能权限保持有效。

## English
- **Sync external brightness with built-in display**: a new toggle in **Settings → Displays → External Displays** and below the menu bar brightness sliders lets external monitors follow your MacBook's built-in display brightness. When the built-in screen adjusts to ambient light or manual brightness changes (by 2% or more), external monitors change by the same delta while keeping each monitor's relative brightness offset. Syncing pauses automatically when the lid is closed, the screen is locked, or the Mac is asleep, and re-establishes its baseline cleanly when woken or reopened.
- **Updating**: from 0.6.1 or later use **Check for Updates…**; Accessibility permission is kept. Self-signed, not notarized: right-click → Open on first launch.
