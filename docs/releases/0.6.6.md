# LayoutKeeper 0.6.6

## 新功能
- **界面语言设置**：设置 → 通用 → 语言，可选「跟随系统」、English 或简体中文。切换后点「立即重启」即可生效。

## 改动
- **更新说明直接显示在更新窗口里**：检查到新版本时，弹窗里显示简短的中文或英文更新说明（跟随界面语言），不再加载 GitHub 网页；底部保留一个查看完整说明的链接。
- **安装位置显示真实路径**：设置 → 通用 → 关于 里不再出现令人困惑的「测试候选」，改为显示应用实际所在的路径，并提供「在 Finder 中显示」按钮。只有从源码构建的开发版本才会标注「开发构建」。

## 更新
0.6.1 及以上：菜单栏 → **检查更新…**，辅助功能权限保持有效。

## 下载哪个文件？
| 你的 Mac | 下载 |
| --- | --- |
| Apple 芯片（M1 / M2 / M3 / M4 / M5…） | `LayoutKeeper-0.6.6-AppleSilicon.dmg` |
| Intel 处理器 | `LayoutKeeper-0.6.6-Intel.dmg` |

`.zip` 和 `appcast-*.xml` 供应用内更新使用。自签名、未经 Apple 公证：第一次打开请右键 → 打开。

## English
- **Language setting**: Settings → General → Language lets you choose Follow System, English or 简体中文. Click **Relaunch Now** to apply it.
- **Release notes inside the update window**: when an update is available, the dialog shows short release notes in your interface language instead of loading the GitHub page. A link to the full notes stays at the bottom.
- **Real install location**: Settings → General → About no longer shows the confusing "test candidate" label. It shows where the app actually lives, with a **Show in Finder** button. Only builds made from source are marked "Development build".
- **Updating**: from 0.6.1 or later use **Check for Updates…**; Accessibility permission is kept. Self-signed, not notarized: right-click → Open on first launch.
