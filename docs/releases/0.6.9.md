# LayoutKeeper 0.6.9

## 改动
- **窗口按原来的桌面放回**：以前恢复时按「第几个桌面」来放，桌面一增一减顺序就错了，换着接不同的显示器、或者重新插拔后，窗口容易被叠到同一个桌面上。现在每组窗口记住的是它自己所在的那个桌面，那个桌面还在就放回那里；不在了就按原来的先后顺序依次放，不会把两组挤到一起。
- **接着外接屏时自动记录布局**：外接屏接着的时候，LayoutKeeper 会定时记下当前的窗口布局，拔屏时停下。新开的窗口（比如刚打开的编辑器窗口）就算没手动保存过，下次接上也能放回去。
- **桌面不够时先补，不硬塞**：外接屏上的桌面比记录的少时，先自动补齐桌面再放窗口；补不上就让剩下的窗口留在原地，并告诉你还缺几个桌面。
- **保存的窗口已关闭时会说明**：保存的布局里有些窗口已经关掉了，会直接告诉你，不会拿别的窗口去顶替。
- **音量键始终调 Mac 本机的音量**：不管鼠标在哪块屏幕上，音量键都调 Mac 当前的声音输出，每次 3%，⌥⇧ 微调 1%。外接屏的音量滑块已去掉。亮度键不变，仍然调鼠标所在的屏幕。
- 自动补桌面时打开调度中心失败会重试几次。
- 日志更安静：只在窗口布局真正变化时才记一行。

## English
- **Windows go back to their own desktop**: restore used to place windows by desktop position (the 2nd desktop, the 3rd…), so once a desktop was added or removed the order was off, and after replugging or switching monitors windows could pile up on one desktop. Each group of windows now remembers the desktop it was on and goes back there if it still exists; if it doesn't, groups are placed in their original order and never squeezed together.
- **The layout is recorded while an external monitor is attached**: LayoutKeeper keeps a record of your windows while the monitor is plugged in and stops when you unplug. Windows you opened recently, such as a new editor window, come back next time even if you never saved.
- **Missing desktops are added first, not squeezed**: if the monitor has fewer desktops than recorded, LayoutKeeper adds them before moving windows. If it can't, the remaining windows stay where they are and you're told how many desktops are missing.
- **Closed windows are reported**: if some saved windows have been closed, LayoutKeeper says so instead of putting other windows in their place.
- **Volume keys always control the Mac's own volume**: wherever the mouse is, the volume keys change the Mac's current sound output, 3% per press, ⌥⇧ for 1%. The external monitor volume sliders are gone. Brightness keys are unchanged and still follow the screen under the mouse.
- Opening Mission Control to add desktops is retried a few times if it fails.
- Quieter log: a line is written only when the window layout actually changes.
- **Updating**: from 0.6.1 or later use **Check for Updates…**; Accessibility permission is kept. Self-signed, not notarized: right-click → Open on first launch.
