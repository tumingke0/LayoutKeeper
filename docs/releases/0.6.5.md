# LayoutKeeper 0.6.5

## 新功能
- **英文界面**：菜单、主窗口、设置、使用引导、恢复预览、提示和亮度提示都有了英文版。界面语言跟随系统：系统是中文时显示简体中文，其他语言显示英文。

## 改动
- 修正使用引导里的权限说明：以前写「不联网」不准确，现在说明布局只保存在本机、不读取窗口内容，唯一的联网是可关闭的 GitHub 更新检查。
- 去掉了引导里关于 ad-hoc 签名需要重新授权的旧提示（0.6.1 起使用固定签名，更新后权限保持有效）。
- 英文界面下的日期、单复数和较长文字做了排版调整；中文界面不变。

## 更新
0.6.1 及以上：菜单栏 → **检查更新…**，辅助功能权限保持有效。

## 下载哪个文件？
| 你的 Mac | 下载 |
| --- | --- |
| Apple 芯片（M1 / M2 / M3 / M4 / M5…） | `LayoutKeeper-0.6.5-AppleSilicon.dmg` |

`.zip` 和 `appcast-*.xml` 供应用内更新使用。自签名、未经 Apple 公证：第一次打开请右键 → 打开。

## English
- **English UI**: menus, main window, settings, setup guide, restore preview, notices and the brightness indicator are now available in English. The app follows your system language: Simplified Chinese on Chinese systems, English everywhere else.
- **Setup guide fix**: the permission text no longer claims the app never goes online. It now says layouts stay on your Mac, window contents are never read, and the only network access is the optional GitHub update check. The outdated ad-hoc re-signing hint was removed.
- Layout tweaks for longer English text, dates and singular/plural; the Chinese UI is unchanged.
- **Updating**: from 0.6.1 or later use **Check for Updates…**; Accessibility permission is kept. Self-signed, not notarized: right-click → Open on first launch.
